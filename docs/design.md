# Design

Kilnbridge uses Jourloy's Atmosphere reference (`monorepo-frontend/docs/design/00.md`):
a warm paper ground, wine accents, quiet surfaces, and Inter typography. This document
records the relevant tokens so contributors do not need access to another repository.

| Token | Value |
| --- | --- |
| Ground | `#F5F1EA` |
| Surface | `#FFFCF8` |
| Text | `#2C252B` |
| Muted text | `#6E646B` |
| Accent | `#783A50` |
| Soft accent | `#EEE0E5` |
| Control outline | `#93818B` |
| Card radius | 22 px |
| Input radius | 12 px |
| Button radius | Pill |
| Spacing scale | 4, 8, 12, 16, 24, 32, 48 px |

Use a clear hierarchy, restrained gradients, 44 px action targets, and a visible
2 px focus outline. Honor reduced motion. Decorative art uses simple sketch strokes
and a limited accent fill. The bridge mark and illustration are original SVG assets.
Inter is bundled locally under the SIL Open Font License, included next to the font.
There are no CDN requests or remote fonts in the settings interface.
